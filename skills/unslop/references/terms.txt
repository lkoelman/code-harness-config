# Candidate patterns for find-slop.sh. Format: <category>|<extended regex>
# Matching is case-insensitive. One pattern per line; '#' starts a comment.
#
# These patterns LOCATE candidates, they do not judge them. Every hit needs a
# human or model decision, because the same word is slop in prose and correct
# in code: `surface` is a metaphor in a design document and a legitimate
# identifier in a graphics library. Expect false positives and triage them.
#
# Categories map to the directives in harnesses/claude/CLAUDE.md:
#   metaphor     NAME THE MECHANISM, NOT A METAPHOR
#   unqualified  QUALIFY ALL TERMS
#   relational   CONTEXTUALIZE RELATIONAL JARGON
#   unmeasurable claims a reader cannot check (NASA Appendix C list)
#   filler       words that occupy the position a claim should occupy
#   contrast     false-contrast constructions that assert instead of stating
